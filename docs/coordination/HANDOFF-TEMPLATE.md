# Agent Handoff

Copy this into the GitHub Issue before pausing or completing a task.

```text
SYNC — HANDOFF
Agent:
Issue:
Branch:
Latest commit:
Current state: (in progress / ready for review / blocked / complete)

Delivered:
Files changed:
Contracts / APIs / events / migrations affected:
Tests run (exact commands + results):
Tests not run and why:
CI status / link:
Known defects or limitations:
Decisions needed:
Dependencies / affected agents:
Recommended next action:
```

A handoff is not complete if it omits test evidence, uncommitted work, unresolved conflicts or known risks.
