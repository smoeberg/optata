> **Rettelse (markedsambitionen, struktur C):** M3 som invitation/lead-kanal
> er forkastet. Mægleren bliver **deltager med scoped adgang**
> (participation_license), ikke abonnent med leads — og kampagner
> (målrettet rækkevidde) kommer forud for mandat og budbog i sekvensen. Se
> `docs/design/Optata - Efterspoergselsgravitation - struktur C v1.md` §8–9
> og `docs/design/Optata - Maalrettet raekkevidde - Campaign v1.md` §10.

**Omfang:** 24 persondage · **Afhængigheder:** S5 grøn (relay) · **pilot-feed-aftale underskrevet** · L32–L35 besvaret
**Mål:** Køberen får værdi dag ét. Mægleren bliver leverandør og lead.

## C2 · Acceptkriterier

```
S6-01  GIVEN ingen aktiv license_ref     THEN adapter deaktiveret, 0 records importeret
       GIVEN licens udløbet              THEN import stopper, eksisterende skjules efter 30 dage

S6-02  GIVEN prisændring                THEN ny version, valid_to på gammel, historik bevares
       GIVEN samme (source, ref, changed_at) THEN 0 duplikater

S6-03  GIVEN afbrudt kørsel             THEN genoptages fra checkpoint
       GIVEN schema-fejl                THEN karantæne, aldrig stille drop

S6-04  GIVEN XML-feed                   THEN normaliseres til kanonisk JSON, samme validering
       GIVEN personfelt i feed          THEN schema afviser (seller_name/owner/buyer)

S6-05  GIVEN andelsbolig-udbud (FX-L2)  THEN korrekt adresse-id, ikke hele BFE
       GIVEN 12 kandidater (FX-L3)      THEN manuel kø, men gade-match virker
       GIVEN kun vej-match              THEN M3 muligt, M1 umuligt

S6-06  GIVEN gade-ordre                 THEN kun udbud på den gade
       GIVEN kommune-ordre              THEN alle udbud i kommunen
       GIVEN samme husstand+scope+id    THEN 409 (dedup)

S6-07  GIVEN match                      THEN score + reason_codes non-empty
       GIVEN CURIOS-ordre               THEN match synligt, kontakt blokeret

S6-08  GIVEN 5 nye matches samme dag    THEN 1 samlet notifikation
       GIVEN prisændring                THEN max 1 pr. 7 dage pr. bolig
       GIVEN SOLD/WITHDRAWN/STALE       THEN ingen notifikation

S6-09  GIVEN udbud vist                 THEN mæglerens navn + link til annonce synligt
       GIVEN ingen attribution          THEN kan ikke renders (guard)

S6-10  GIVEN CURIOS/QUALIFIED køber     THEN ingen invitation, opgraderings-CTA
       GIVEN mægler uden CVR-match      THEN 403, intet køberdata vist
       GIVEN 3 købere til samme bolig   THEN 1 invitation med antal
       GIVEN mægler afmeldt             THEN ingen invitation

S6-11  GIVEN M3-dialog                  THEN salgspakke tilbydes ALDRIG
       GIVEN reveal i M3                THEN 4 guards, ingen betalingscheck
       THEN audit channel=AGENT, samme vault-indgang

S6-12  GIVEN SOLD i feed                THEN match fjernet, tråd markeret
       GIVEN ACTIVE forsvundet fra feed THEN STALE, ikke SOLD

S6-13  GIVEN FX-L1…L8                   THEN alle grønne før merge
```

## C3 · Definition of Done S6

Alle guards grønne · ingen import uden licens · attribution synlig · VERIFIED-gate på invitation · CVR-match på mægler · **ingen pakke i M3** · reveal-variant dokumenteret i ADR-008/017 · STALE ≠ SOLD · ADR-016/017/018 opdateret · runbooks skrevet · DK-review på røde felter.

**Forretningsmilepæl:** S6 grøn = køberen får værdi dag ét (P0 lettere), mægleren bliver feed-leverandør og lead, og **M3 kan måles**: match-rate, invitation→registrering, gratis-svar→abonnement.
