## A2 · Acceptkriterier

```
S4-01  GIVEN andelsbolig (FX-01)     THEN EJF-match må IKKE anvendes
       GIVEN selskab + MitID Erhverv THEN CVR-match → VERIFIED
       GIVEN intet register-match    THEN PENDING_MANUAL, ingen visning

S4-02  GIVEN EJF-adgang afvist       THEN adapter deaktiveret, fallback aktiv
       GIVEN navnematch              THEN transient, intet navn gemt/logget

S4-03  GIVEN tinglyst adkomst        THEN confidence=MEDIUM, ttl=90d
       GIVEN ny ejer ikke tinglyst   THEN flag + manuel kø tilbydes

S4-04  GIVEN andelsbevis uploadet    THEN manuel kø, 2 hverdage SLA vist
       GIVEN godkendt                THEN ownership VERIFIED, ttl=180d

S4-05  GIVEN sameje med 2 ejere      THEN reveal kræver BEGGE verifikationer
       GIVEN fuldmagt                THEN altid manuel + jurist-reference

S4-06  GIVEN ejerskifte i registry   THEN eksisterende ownership → EXPIRED
       THEN adgang fjernet øjeblikkeligt, ejer notificeret sagligt
       GIVEN tidligere ejer logger ind THEN 403 OWNERSHIP_NOT_VERIFIED

S4-07  GIVEN samtykke                THEN purpose + scope + text_version + legal_basis_ref
       GIVEN tilbagekaldelse         THEN suppression øjeblikkelig, åben tråd ABORTED

S4-08  GIVEN 3 interesser samme adresse inden 14 dage THEN 1 samlet mail
       GIVEN QUALIFIED (ikke VERIFIED) THEN ingen notifikation
       GIVEN kl. 22                  THEN kø til 08:00
       GIVEN afmeldt adresse         THEN ingen mail, uanset nye interesser
       GIVEN scope=AREA              THEN aldrig owner.notified

S4-09  GIVEN mail renderet           THEN ingen navn, beløb, telefon, e-mail
       GIVEN token udløbet           THEN "Linket er udløbet. Slå adressen op igen."
       GIVEN afmeld klikket          THEN suppression + kvitteringsside

S4-10  GIVEN ejer uden e-mail        THEN brev skabelon genereret, samme regler

S4-11  GIVEN uverificeret ejerskab   THEN 403, ingen interest-data
       GIVEN betalt adgang           THEN 12 uger, adresse-scopet, RLS håndhævet
       GIVEN udløbet                 THEN 402 SUBSCRIPTION_EXPIRED

S4-12  GIVEN waiver ikke accepteret  THEN levering blokeret (fortrydelsesret)
       GIVEN betaling gennemført     THEN adgang øjeblikkelig, kvittering + audit
       GIVEN fortrydelse inden 14 dage THEN kreditnota, egen serie

S4-13  GIVEN alle fixtures           THEN grønne før merge
```

## A3 · Definition of Done S4

Alle guards grønne · **ingen visning uden ejerskabsverifikation** · ejerskifte tilbagekalder adgang · notifikation overholder loft/quiet hours/afmeld · waiver implementeret · ADR-009 opdateret · runbooks `notify-failed` og `ownership-dispute` skrevet · DK-review på S4-01/06/07/13.

**Forretningsmilepæl:** S4 grøn = **A2 kan måles** (≥15 % ejerrespons) og ejersiden kan sælges fra md. 9.
