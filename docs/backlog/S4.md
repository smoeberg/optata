# Sprint S4 — SaleMandate og sælgerens mandatoplevelse

**Status:** Design/planlagt · produktionsimplementering blokeret af LG-1, LG-2 og LG-5  
**Mål:** En verificeret ejer kan oprette, godkende og tilbagekalde et præcist mandat, som Optata kan bruge til platformshandlinger inden for juridisk godkendt scope.

## Scope
- Ejendoms-/adressekobling og ownership evidence.
- Mandatparter med individuelle godkendelser.
- Sameje, fuldmagt, dødsbo og andelsbolig som særskilte review paths.
- Versionerede mandatvilkår og scopes.
- Executor mode: DIRECT eller AGENT_EXECUTED.
- Conflict detection, suspension, revocation and expiry.
- Audit, notifications only where separately opted in, and owner UI.

**Ude:** gammel betalt ejerside som selvstændigt indsigtsprodukt; uopfordret brev/mail/Digital Post; 12-ugers adgang; automatisk ejerkontakt ved match.

## Datamodel — minimum
- `sale_mandate`: id, property/address, mandate_type, scope, executor_mode, status, terms_version, valid_from/to, created_at.
- `mandate_party`: mandate_id, identity_id, party_role, evidence_ref, approval_status, approved_at, revoked_at.
- `mandate_executor`: mandate_id, organization_id, executor_type, participation_license_id, scope, status.
- `mandate_event`: append-only event log for create, party approval, activation, suspension, revocation, expiry and completion.

En enkelt `owner_identity`-kolonne kan ikke repræsentere sameje og må ikke være den autoritative partsmodel.

## State model
DRAFT → PARTIES_PENDING → EVIDENCE_REVIEW → READY_FOR_ACTIVATION → ACTIVE → SUSPENDED / REVOKED / EXPIRED / COMPLETED.
Kun domænekommandoen `activate_mandate` kan aktivere mandatet. UI må ikke sætte status direkte.

## Acceptkriterier
- Mandat kan ikke aktiveres, før alle nødvendige parter er identificeret og individuelt har accepteret samme terms_version.
- Ownership evidence og authority evidence er adskilte og kan have forskellige udløb.
- Sameje med manglende part, ugyldig fuldmagt eller uløst ejerskifte giver fail-closed afvisning.
- Konfliktregel for flere ejendoms-/adresseidentiteter er eksplicit; databaseconstraint og transaktion forhindrer race.
- Mandatets scope og executor mode er immutable per version; ændring kræver ny version og genaccept.
- Tilbagekaldelse/suspension blokerer nye bud, kampagner og executor access straks; eksisterende audit bevares.
- Partner ser kun det konkrete mandat og opgaver, som participation license tillader.
- Ingen mandatflow sender uopfordret besked til ejer eller køber.

## Release gates
LG-1, LG-2 og LG-5 skal være skriftligt lukket. L41 skal omsættes til konkrete vilkår. EJF/Tingbog/andelsbeviser kræver dokumenterede adgangs- og behandlingsrettigheder.

## Definition of Done
Menneskegodkendte vilkår, migrationer og guards; race-/TOCTOU-tests; alle parter auditeret; tilbagekaldelse testet end-to-end; partner-scope verificeret i DB/RLS; ingen prod-aktivering før release gate.
