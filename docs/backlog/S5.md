> **Rettelse (markedsambitionen, struktur C):** S5 bliver **OfferLedger +
> begrænset beskedfelt** i stedet for fri relay-chat — mindre redaction,
> mere marked. Se
> `docs/design/Optata - Efterspoergselsgravitation - struktur C v1.md` §9.

**Omfang:** 30 persondage · uge 16–22 · **Afhængigheder:** S4 grøn · **L1–L3, L21–L24 besvaret** · advokatpartner-aftale underskrevet

## B2 · Acceptkriterier

```
S5-01  GIVEN ikke-deltager            THEN 403 på tråd (RLS, ikke UI)
       GIVEN besked slettet?         THEN umuligt — append-only
       GIVEN mægler                  THEN aldrig deltager i deal

S5-02  GIVEN "ring 2045 6677"        THEN blokeret + message.redacted(rule=PHONE)
       GIVEN "a@b.dk" / URL / kontonr THEN blokeret
       GIVEN CPR-mønster             THEN blokeret, aldrig logget i klartekst

S5-03  GIVEN billede med EXIF-GPS    THEN strippet før lagring
       GIVEN billede med navneskilt  THEN OCR-træff → afvist
       GIVEN .docx/.zip              THEN afvist (kun PDF/JPG/PNG)

S5-04  GIVEN "ring nul nul…"         THEN adfærdslag fanger, blokeret
       GIVEN 3 forsøg samme tråd     THEN karantæne + eskalering
       GIVEN gentagne forsøg på tværs THEN repeat_offender-flag

S5-05  GIVEN LLM nede                THEN lag 1–5 beskytter stadig (ikke afhængig)
       GIVEN LLM-kald                THEN EU-endpoint, ingen zone B til træning

S5-06  GIVEN afvist besked           THEN forklaring vist, intet indhold i log
       GIVEN redaction-træff         THEN content_hash logges, ikke tekst

S5-07  GIVEN PRICE_AGREED            THEN agreed_terms_hash låses, beskeder kan ikke ændre det
       GIVEN kun én part bekræfter   THEN state forbliver DIALOG_OPEN

S5-08  GIVEN enighed                 THEN "ikke bindende" tekst vist for begge
       GIVEN vilkår ændret efter     THEN ny hash + ny bekræftelse fra begge

S5-09  GIVEN pakke accepteret        THEN fast 10.000, ingen %-beregning noget sted
       GIVEN betaling fejlet         THEN state tilbage, ingen reveal mulig
       GIVEN escrow-forsøg i kode    THEN CI-test afviser (ingen købesum-håndtering)

S5-10  GIVEN ét af 6 guards mangler  THEN 409/403, INGEN vault-læsning i audit
       GIVEN to samtidige kald       THEN ét grant, idempotent, ny audit-entry
       GIVEN attest udløber mellem check og brug THEN afvist (TOCTOU, lås i transaktion)
       GIVEN step-up 6 min gammel    THEN 403 STEP_UP_REQUIRED

S5-11  GIVEN reveal                  THEN audit skrives FØR data returneres
       GIVEN admin/support-endpoint  THEN findes ingen vej til vault
       GIVEN gentaget reveal         THEN samme grant returneres

S5-12  GIVEN partner-sag             THEN kun nødvendige felter, ingen tråd-historik
       GIVEN partner                 THEN selvstændig dataansvarlig, DPA på plads

S5-13  GIVEN ejer afmelder midt i    THEN tråd ABORTED, køber informeret anonymt
       GIVEN attest udløber i dialog THEN deal tilbage til DIALOG, ikke reveal

S5-14  GIVEN 50+ redaction-varianter THEN alle fanget af deterministisk lag
       GIVEN alle guards isoleret    THEN hver afviser enkeltvis
```

## B3 · Definition of Done S5

Alle guards grønne · redaction fungerer **uden** LLM · reveal kun via disclosure med audit-før-retur · race og TOCTOU testet · ingen escrow-logik · partner-DPA underskrevet · ADR-007/008 opdateret med juristens svar · runbooks `redaction-bypass` og `reveal-anomaly` skrevet · DK-review på alle syv røde issues.

**Forretningsmilepæl:** S5 grøn = transaktionsbenet kan åbne (md. 12+), pakke-uptake kan måles, og **disintermediation er håndhævet i kode**.
