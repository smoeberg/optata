# Sprint S3 — MitID, ordre, attest og vault

**Status:** Planlagt · bygger på syntetiske data indtil LG-2 er lukket  
**Mål:** En person kan oprette en købsordre med MitID og få købevnen verificeret på en sikker, auditerbar måde.  
**Afhænger af:** S0 review af zone-/vault-migrationer; S1 ordregeografi; MitID-broker; juristens L11–L16.

## Scope
- OIDC/MitID private login og session lifecycle.
- Identitetsmapping til intern pseudonym identity; CPR må ikke persisteres.
- Vault med separat DB-rolle og disclosure-only adgang.
- Step-up authentication til følsomme handlinger.
- Order create/update med QUALIFIED og VERIFIED status.
- Attest upload, kryptering, hash, review, dual control og expiry.
- Household dedup og co-buyer.
- Audit, retention og incident runbooks.

**Udtrykkeligt ude:** e-mail-identitet, magic link, CURIOS, e-mail→MitID upgrade, lead-lister, kontakt til ejer, mæglerinvitation og ejerside.

## Acceptkriterier
- MitID callback validates issuer, audience, state, nonce and signature; invalid/replayed callback fails closed.
- CPR is absent from DB, logs, traces, events, fixtures and error reports.
- App/public roles cannot SELECT vault; disclosure service has the only scoped grant.
- QUALIFIED cannot bid, enter VERIFIED density, or trigger owner/agent communication.
- VERIFIED requires approved evidence with issuer/source, reviewer, decision timestamp and expires_at.
- Expiry worker downgrades VERIFIED and revokes bid eligibility before any subsequent command succeeds.
- Household duplicate returns deterministic conflict or offers co-buyer flow; no duplicate active order.
- Consent records include purpose, scope, text_version, legal_basis_ref (when approved), granted_at and revoked_at/history.
- Audit is written before sensitive response; trace_id follows the command and emitted events.
- All failure paths fail closed; no PII in synthetic fixtures.

## Release gates
- LG-2 closed before real personal data or production attest.
- MitID broker contract and DPIA/retention rules documented.
- Human review of vault grants, migrations, expiry and guards.
- No unresolved critical/high security finding.

## Definition of Done
Contracts + migrations + code + tests + runbooks agree; all guards green; human security review signed; retention and incident procedures tested. S3 does not grant permission to contact owners or run mandates.
